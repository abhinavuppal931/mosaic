- **JetBrains Mono** (`public/fonts/jetbrains-mono-latin.woff2`): SIL Open Font License 1.1, text in `public/fonts/OFL-JetBrainsMono.txt`.
- **Brygada 1918** (`public/fonts/brygada-1918-700-latin.woff2`, the wordmark only): SIL Open Font License 1.1, text in `public/fonts/OFL-Brygada1918.txt`.
- **Switzer** is not included. Its ITF Free Font License (section 02) does not allow sharing the font files through a repository, so the page loads it from the Fontshare API and falls back to the system sans when offline.
- **Portraits and the table scene** in `public/img/` are copies of `docs/design/assets/`. The portraits are stylized illustrations generated for this project with an image model from a style reference (see `docs/design/round1-synthesis.md`). They are not photographs. They depict simulated seats, and the people shown are not affiliated with Mosaic and have not endorsed it.
